# Bid By Bits — Документация на проекта

## 1. Увод

### 1.1 Концепция на проекта

**Bid By Bits** е уеб приложение за онлайн търгове и продажба на колекционерски предмети и second-hand артикули, насочено към българския пазар. Платформата комбинира класическия модел на интернет търгове с механизми за защита на купувачите и продавачите, характерни за българската среда на разплащания при доставка (cash on delivery).

Основната идея е да се попълни вакуумът в българския онлайн пазар за втора употреба — липсата на доверие между непознати страни. Чрез система от рейтинги, проследяване на доставки и механизми срещу отказ от получаване на пратки, платформата създава прозрачна и подотчетна среда както за еднократни продавачи, така и за сериозни колекционери.

### 1.2 Цел на проекта

Целта на проекта е да се разработи функционално уеб приложение, което:
- Осигурява сигурна платформа за онлайн търгове и директни продажби
- Въвежда система за кредитна репутация на продавачите
- Предоставя механизми за защита на купувачите при доставка
- Създава прозрачен и отговорен пазар за second-hand и колекционерски предмети

### 1.3 Основни задачи

1. **Изследване на българския пазар** за втора употреба и анализ на съществуващи платформи (olx.bg, bazar.bg, Vinted)
2. **Дизайн на архитектура** — избор на технологичен стек (ASP.NET Core MVC + EF Core + SQL/SQLite)
3. **Проектиране на база данни** — модели за потребители, артикули, оферти, поръчки, рейтинги и логуване на доверие
4. **Реализация на бекенд** — CRUD операции, бизнес логика за търгове, обработка на поръчки
5. **Реализация на фронтенд** — потребителски интерфейс с ASP.NET MVC Views (Bootstrap)
6. **Система за автентикация и оторизация** — регистрация, вход, роли (купувач/продавач)
7. **Механизми за защита** — рейтингова система, логуване на откази от доставка, проследяване на доказателства

### 1.4 Очаквани резултати

- Работещо уеб приложение с пълна CRUD функционалност за артикули
- Система за онлайн търгове с реално време (базирани на таймери)
- Механизъм за директна продажба (фиксирана цена или "най-добра оферта")
- Рейтинг система за продавачи (1-5 звезди с коментари)
- Система за проследяване на доставки и откази
- Документация: технически дизайн, ръководство за употреба, код

## 2. Предварително проучване

### 2.1 Анализ на съществуващи решения

| Платформа | Търгове | Директна продажба | Рейтинги | Защита купувач | Български пазар |
|-----------|---------|-------------------|----------|----------------|-----------------|
| OLX.bg    | Не      | Да                | Частичен  | Няма           | Да              |
| Bazar.bg  | Не      | Да                | Няма     | Няма           | Да              |
| Vinted    | Не      | Да (фиксирана)    | Да       | Да (фонд)      | Да              |
| eBay      | Да      | Да                | Да       | Частична       | Международен    |

**Намерени пропуски:** Нито една от съществуващите български платформи не предлага комбинация от търгове + система за репутация + механизми срещу отказ от доставка. Това е основната конкурентна предимство на Bid By Bits.

### 2.2 Технологичен стек

| Компонент     | Избор            | Обосновка                          |
|---------------|------------------|-------------------------------------|
| Backend       | ASP.NET Core 10  | Крос-платформен, висок performans, официална поддръжка до 2026 |
| ORM           | Entity Framework Core | Code-first подход, миграции, LINQ |
| Database      | SQLite (dev) / SQL Server (prod) | SQLite за разработка, SQL Server за production |
| Frontend      | ASP.NET MVC + Bootstrap 5 | Server-side rendering, responsive дизайн |
| Auth          | ASP.NET Core Identity (custom) | Гъвкавост за ролева система |
| Version Control | Git + GitHub   | Стандарт в индустрията              |

### 2.3 Рискове и ограничения

- **Технологичен:** .NET 10 е много нова версия — възможни бъгове в библиотеките
- **Пазарен:** Българският пазар за second-hand е малък — нужни са критична маса потребители
- **Технически:** Реално време за оферти изисква SignalR или подобен механизъм (план за бъдеща фаза)

## 3. Планирани функционалности

### 3.1 За купувачи
- Регистрация и вход в системата
- Разглеждане на активни търгове и директни продажби
- Правене на оферти (bid) за артикули в търгове
- Покупка на артикули с фиксирана цена или най-добра оферта
- Проследяване на поръчки и статус на доставка
- Оставяне на рейтинг и коментар за продавач след транзакция

### 3.2 За продавачи
- Регистрация и верификация на профил
- Създаване на артикул (търговска или фиксирана цена)
- Управление на активни listings
- Проследяване на продажби и приходи
- Визуализация на кредитния рейтинг

### 3.3 Система за защита
- **Рейтингова система:** Всеки потребител вижда средния рейтинг на продавача (1-5 звезди) преди покупка
- **Логуване на откази:** Ако купувач откаже доставка, това се логува и намалява репутацията му
- **Доказателства:** Купувачът може да качи доказателство за връщане на пратка, за да разреши спора
- **Проследяване на доставки:** Всяка поръчка има статус (платена, изпратена, доставена, отказана)

### 3.4 Административни функции (фаза 2)
- Управление на потребители (блокиране/деактивиране)
- Модериране на артикули
- Статистики и отчети

│   ├── Controllers/             # Контролери
