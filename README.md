Bid By Bits - Web Appllication for online auction and selling of collectables and second hand items. 

By leveraging the robust architecture of the .NET 10 framework and ASP.NET MVC, Bid By Bits ensures a seamless, responsive user experience even during high-traffic, time-sensitive auction events. The integration of Entity Framework Core with a secure SQL database guarantees reliable, real-time data management for live bids, transaction histories, and the credibility scoring system. Ultimately, the platform bridges the gap between traditional second-hand trading and modern e-commerce security, creating a transparent and highly accountable marketplace for both casual sellers and dedicated collectors.
The app is provides of 2 main options for selling a item. A buyer could either auction it on a set date or sell it for given price which could also be set to best offer. 

The platform provides multiple buyer and seller protection mechanism in which are consistent with bulgaria's cash on delivery payments and including buyer sugested seller credability scores, helping users avoid unfair sellers.

Another issue that is going to be solved is the addition of a feature that logs each time buyer order a package and refuse to get accept their package and force the buyer to pay the wayback delivery. This bad score will be visible to all sellers and it could be removed only after paying via 3rd party payment service and submitting proof the delivery to the seller or it could be ignored if the buyer negotiated with the seller for a delivery prepayment.
